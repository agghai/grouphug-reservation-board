# GroupHug Reservation Board v1.7

오늘 하루의 공간 예약 현황만 보여주는 Node.js + Express 예약 보드입니다. 실제 데이터는 Notion Data Source에서 읽고, `MOCK_DATA=true`일 때는 서버의 샘플 데이터를 사용합니다.

## v1.2 변경사항

- 7일 날짜 선택 달력 제거: 오늘 예약만 조회
- 새로고침 버튼: 서버 캐시를 무시하고 Notion을 즉시 다시 조회
- 전체화면 모드 추가
- 전체화면 종료 버튼 클릭 시 관리자 비밀번호 확인
- 사용자가 `Esc` 등 브라우저 기능으로 전체화면을 빠져나오면 화면 잠금 오버레이 표시
- 잠금 비밀번호는 프론트 코드가 아니라 서버의 `KIOSK_PASSWORD` 환경변수로 검증
- 기본 룸 예시를 `A룸,B룸,세미나룸`으로 변경
- `15인이하-세미나룸`, `6인이하-세미나룸`은 `세미나룸`으로 통합 가능
- 현재 시간 강조 / 지난 시간 회색 처리 / 예약 가능 가독성 UI 유지

## 실행

```bash
npm install
cp .env.example .env
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 테스트용 설정

`.env`:

```env
ROOMS=A룸,B룸,세미나룸
MOCK_DATA=true
KIOSK_PASSWORD=1234
```

`MOCK_DATA=true`면 Notion 연결 없이 오늘 날짜의 더미 예약으로 UI를 테스트할 수 있습니다.

## Notion 연결

```env
MOCK_DATA=false
NOTION_TOKEN=ntn_xxxxxxxxx
NOTION_DATA_SOURCE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
PROP_NAME=업체명
PROP_ROOM=예약룸
PROP_DATE=예약시간
```

새로고침 버튼을 누르면 `/api/schedule?...&refresh=1` 요청을 보내 서버 캐시를 건너뛰고 Notion에서 오늘 예약 목록을 다시 읽습니다.

## 전체화면 비밀번호

```env
KIOSK_PASSWORD=원하는비밀번호
```

테스트 기본값은 `1234`입니다. 실제 운영 전에는 반드시 변경하세요.

브라우저 보안 정책상 `Esc` 키 자체로 전체화면 종료를 막을 수는 없습니다. 대신 이 버전은 비정상적으로 전체화면이 종료되면 즉시 화면을 잠그고, 비밀번호가 맞아야 다시 조작할 수 있게 처리합니다.

## UI v1.3 변경사항
- 현재 시간 강조 표시 제거
- 상단 문구를 `그룹허그 예약 현황` 하나로 단순화
- 날짜/범례/공간 제목 등 중복 안내 문구 제거
- `예약 가능`은 초록 상태 배지로 단순화
- 예약된 시간은 `예약 완료` 배지와 예약자명을 분리해 예약자명을 더 크게 표시
- 지난 빈 시간은 `지난 시간`으로 표시해 과거 슬롯의 `예약 가능` 오해 방지
- 지난 시간 회색 처리는 유지

## v1.4 UI

- 룸 선택 탭을 제거하고 A룸/B룸/세미나룸을 한 화면에 동시에 표시합니다.
- 상태 표시는 `예약 가능` 또는 예약자명만 표시합니다.
- 새로고침 시 `/api/schedule-all?refresh=1`을 호출해 캐시를 건너뛰고 Notion 데이터를 한 번 다시 조회합니다.
- 지난 시간은 회색 처리만 유지하며 현재 시간 별도 강조는 없습니다.
- 전체화면/비밀번호 잠금 기능은 그대로 유지됩니다.

## v1.5 UI
- A룸/B룸/세미나룸 전체 현황을 한 화면에서 비교
- 그룹허그 보라색 계열(#4c0bce) 기반의 라벤더 UI

- 현재 시간 강조 없음 / 지난 시간만 회색 처리


## v1.6 UI 변경

- 상단 `그룹허그 예약 현황`과 화면 제어 버튼은 화면에 고정됩니다.
- 예약표 영역만 독립적으로 세로/가로 스크롤됩니다.
- 기본 시간 범위가 `00:00 ~ 24:00`으로 변경되었습니다.
- 표의 컬럼 헤더(`시간 / A룸 / B룸 / 세미나룸`)도 스크롤 중 상단에 고정됩니다.
- 오늘 화면을 처음 열거나 새로고침하면 현재 시간대 근처로 자동 스크롤됩니다. 현재 시간 강조 표시는 사용하지 않습니다.
- 기존 `.env`를 재사용하는 경우 `OPEN_HOUR=0`, `CLOSE_HOUR=24`로 수정해야 합니다.


## v1.7 UI 변경

- 라벤더 배경 면적을 크게 줄이고 화이트 + 웜그레이를 기본 톤으로 변경
- 브랜드 보라색은 상단 포인트 라인, 전체화면 버튼, 예약자명 등 핵심 요소에만 사용
- 예약 가능은 저채도 그레이-퍼플 텍스트로 표시
- 예약된 셀 배경을 거의 흰색으로 낮춰 장시간 표시 시 시각 피로 감소
- 표 테두리와 시간 영역을 웜그레이로 정리해 로비 안내판 느낌 강화
